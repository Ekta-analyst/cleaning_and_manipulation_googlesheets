## 📊 Project Overview
This project focuses on data cleaning and manipulation using *Google Sheets*. The primary goal was to identify dirty elements in the raw dataset and transform the data into a readable, accurate, and visually appealing format ready for analysis.

## 🛠️ Tasks Performed & Steps Taken
* *Spreadsheet Organization:* Renamed the untitled spreadsheet to a relevant and professional title.
* *Duplicate Removal:* Identified and successfully removed duplicate records to ensure data integrity and avoid redundancy.
* *Rating Correction & Counting:* Corrected and standardized ratings, and used rating counts to analyze the distribution.
* *Count Bars Implementation:* Added count bars to visually represent and summarize data trends effectively.
* *Range Sorting:* Applied standard and advanced range sorting techniques to organize the dataset logically.
* *Geospatial Data Cleaning:* Cleaned up and formatted the longitude and latitude data for correct representation.
